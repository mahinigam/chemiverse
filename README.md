An authoritative, museum-grade scientific instrument and chemical intelligence engine built with **Vanilla ES6+ JavaScript, WebGL/Three.js, and Optical Liquid Glass CSS**.

## 🌌 The Vision & Philosophy

Chemistry is not a static lookup table; it is a **continuous, rule-governed quantum universe** governed by thermodynamics, orbital hybridization, electronegativity gradients, and symmetry. Most chemical web apps reduce this universe to rigid binary pairings or static flashcards.

**This instrument is built on a different paradigm:**
1. **Encompassing the Known Universe of Chemistry:**
   Stage any combination of $N$ elements ($N \ge 1$) — from single-element homonuclear allotropes and binary ceramic salts to ternary oxy-acids, quaternary mineral matrices, High-Entropy Alloys (HEAs), and high-temperature superconductors.
2. **First-Principles Computational Engine over Hardcoded Dictionaries:**
   Rather than failing on unlisted pairs, the engine computes chemical feasibility dynamically using fundamental chemical laws: Pauling ionic character, valence electron exchanges, octet satisfaction, spectator inertness barriers, and VSEPR coordination geometries.
3. **Museum-Grade Scientific Instrument Aesthetics:**
   Rejecting generic rainbow gradients, emojis, and amateur UI tropes, this interface is engineered with **Apple VisionOS / Linear / Teenage Engineering** aesthetics: authentic dark obsidian optical liquid glass, physical light refraction, micro-chamfered specular bevels, and spectral emission grading.

## ⚡ Core Capabilities

### 1. The IUPAC Periodic System (118 Elements)
* **Authoritative Grid Coordinate System:** All 118 IUPAC elements placed in strict alignment with Group (1–18) and Period (1–7) coordinates.
* **Separated F-Block Bracket Stage:** Dedicated high-contrast rows for the Lanthanide (57–71, $La \rightarrow Lu$) and Actinide (89–103, $Ac \rightarrow Lr$) series.
* **Continuous Thermal State Engine (0 K to 6000 K):**
  A continuous thermal slider calculates the real-time physical state of all 118 elements simultaneously against their empirical melting and boiling points, updating live state micro-dots and the active thermal regime badge:
  * `0 K – 50 K`: Cryogenic Condensed
  * `51 K – 273.15 K`: Sub-Freezing Solid
  * `273.15 K – 373.15 K`: Standard Ambient (STP)
  * `373.15 K – 1500 K`: Thermal Liquefaction
  * `1500 K – 3500 K`: High Refractory Fluid
  * `> 3500 K`: Vapor / Atomic Gas
* **Real-Time Multi-Attribute Filter:** Filter instantaneously by symbol, name, atomic number ($Z$), or across 10 spectral categories. Supports keyboard escape clear (`ESC`).

### 2. High-Precision Element Inspection Modal
Clicking any element launches a split-screen laboratory examination suite:
* **Interactive 3D Quantum Viewport:**
  * **Quantum Shells Mode:** Realistic clustered nucleus surrounded by inclined 3D electron orbital shells ($K, L, M, N, O, P, Q$) populated with real-time orbiting valence and core electrons.
  * **Elemental State Mode:** Real-world elemental allotrope structure (e.g., $H_2, N_2, O_2, Cl_2$ diatomic dumbbells, diamond covalent network, metallic unit cells, or noble gas atomic spheres).
  * **3D Controls:** Full 360° orbital rotation (left drag), translation (right drag), zoom (scroll), camera reset, and Space-Filling (Van der Waals) toggle.
* **Physical & Electronic Constants Matrix:**
  * Complete electron configuration and condensed noble-gas core notation
  * Valence shell distribution ($2, 8, 18, 32...$)
  * Pauling electronegativity ($\chi$)
  * Atomic and covalent radii (pm)
  * Common and formal oxidation states
  * Precise melting and boiling points in both Celsius (°C) and Kelvin (K)
  * Density at STP ($\text{g/cm}^3$)
  * Standard elemental allotrope form
  * Year of discovery and historic discoverers
* **One-Click Crucible Staging:** Direct button to load the inspected element into the reaction crucible.

### 3. Multi-Element Universal Reaction Crucible ($N \ge 1$)
The crucible enables synthesizing and computing chemical reactions for arbitrary element mixtures:
* **Drag-and-Drop & Click Staging:** Drag elements directly from the periodic table into the crucible or click to stage them.
* **Live Crucible Inspector:** Staged elements display their atomic symbol, name, atomic number, electronegativity, and individual removal controls.
* **Reaction Stoichiometry & Thermodynamics:**
  * Balanced reaction equation with physical states ($2\text{Ti(s)} + \text{N}_2\text{(g)} \rightarrow 2\text{TiN(s)}$).
  * Bonding classification across the full chemical spectrum (Ionic, Polar Covalent, Non-polar Covalent, Metallic Alloy, Interstitial Ceramic, Coordination Complex).
  * Electronegativity gradient ($\Delta\text{EN}$) and Pauling ionic character percentage.
  * Enthalpy of formation ($\Delta H_f^\circ$) and thermodynamic activation barrier conditions.
  * Local VSEPR geometry and bulk space group / crystalline system.
  * Step-by-step quantum orbital mechanism narrative explaining electron transfer, hybridizations ($sp, sp^2, sp^3, sp^3d, d\text{-}p$), and conduction bands.
* **Interactive 3D Molecular Topology:** Real-time 3D rendered ball-and-stick and space-filling representation of the synthesized product.

## 🧪 Chemical Classification & Bonding Spectrum

The reaction engine evaluates combinations across six distinct chemical regimes:

| Regime | Condition / Criteria | Bond Mechanism | Exemplar Reaction |
|---|---|---|---|
| **Noble Gas Inertness** | Any mixture containing $He, Ne, Ar$ (or unreactive $Kr/Xe$) | Complete closed-shell octet ($s^2p^6$); positive free energy ($\Delta G > 0$) acts as spectator | $\text{Ar} + \text{O} \rightarrow \text{No Reaction (Thermodynamic Barrier)}$ |
| **Homonuclear Allotropes** | Single element ($N = 1$) | Self-bonding according to natural state: diatomic gas, metallic bulk, or covalent network | $\text{N} \rightarrow \text{N}_2\text{ (Diatomic Triple Bond, } 1\sigma + 2\pi\text{)}$ |
| **Ionic Lattice** | Metal + Nonmetal with $\Delta\text{EN} \ge 2.0$ | Formal electron transfer from electropositive cation to electronegative anion; electrostatic lattice | $2\text{Na(s)} + \text{Cl}_2\text{(g)} \rightarrow 2\text{NaCl(s) [Halite]}$ |
| **Polar Covalent** | Nonmetals / Metalloids with $0.4 \le \Delta\text{EN} < 2.0$ | Unequal electron sharing producing a net permanent molecular dipole moment | $2\text{H}_2\text{(g)} + \text{O}_2\text{(g)} \rightarrow 2\text{H}_2\text{O(l) [Bent, } 104.5^\circ\text{]}$ |
| **Non-Polar Covalent** | Nonmetals with $\Delta\text{EN} < 0.4$ | Equal electron sharing; symmetric charge distribution | $\text{C(s)} + 2\text{H}_2\text{(g)} \rightarrow \text{CH}_4\text{(g) [Tetrahedral, } T_d\text{]}$ |
| **Interstitial & Intermetallic Alloys** | Transition Metal + Light Element ($C, N, B$) or Metal + Metal | Mixed covalent-metallic bonding; interstitial filling of lattice voids; delocalized conduction bands | $2\text{Ti(s)} + \text{N}_2\text{(g)} \rightarrow 2\text{TiN(s) [Rock-salt FCC]}$ |
| **Multi-Element Systems** | Ternary ($3$) and Quaternary ($4+$) mixtures | Coordinated oxy-anions ($\text{SO}_4^{2-}, \text{NO}_3^-, \text{CO}_3^{2-}$), high-entropy alloys, superconductors | $\text{Y} + \text{Ba} + \text{Cu} + \text{O} \rightarrow \text{YBa}_2\text{Cu}_3\text{O}_7\text{ [YBCO High-}T_c\text{]}$ |

## 🎨 Optical Liquid Glass Design Engineering

Built in accordance with **Emil Kowalski's Design Engineering philosophy** and contrast-verified technical palettes:

### 1. Liquid Glass & Specular Refraction
* **Refractive Edge Thickness:** Utilizes multi-layered specular highlights (`inset 0 1px 0 rgba(255, 255, 255, 0.18)` and `inset 0 1.5px 1px rgba(255, 255, 255, 0.28)`) to create the physical sensation of light entering polished optical quartz.

## 🔬 Curated Reference Benchmarks

The instrument includes 12 instant-load benchmarks representing the pinnacle of chemical variety:
1. **Titanium Nitride ($\text{Ti} + \text{N} \rightarrow \text{TiN}$):** High-hardness interstitial ceramic rock-salt lattice with mixed covalent/metallic bonding.
2. **Ethanol Matrix ($\text{C} + \text{H} + \text{O} \rightarrow \text{C}_2\text{H}_5\text{OH}$):** Organic alcohol with $sp^3$ tetrahedral carbons and bent hydroxyl dipole.
3. **Sulfuric Acid ($\text{H} + \text{O} + \text{S} \rightarrow \text{H}_2\text{SO}_4$):** Dense mineral oxy-acid with resonance-stabilized tetrahedral sulfate group.
4. **Nitric Acid ($\text{H} + \text{N} + \text{O} \rightarrow \text{HNO}_3$):** Planar oxidizing oxy-acid with delocalized $\pi$ bonding.
5. **Calcite ($\text{Ca} + \text{C} + \text{O} \rightarrow \text{CaCO}_3$):** Trigonal planar carbonate anion electrostatically coordinated to $\text{Ca}^{2+}$ cations.
6. **Caustic Soda ($\text{Na} + \text{O} + \text{H} \rightarrow \text{NaOH}$):** Strongly basic ionic hydroxide lattice.
7. **Stainless Steel 316 ($\text{Fe} + \text{Cr} + \text{Ni} + \text{C}$):** Corrosion-resistant austenitic FCC solid solution high-performance alloy.
8. **YBCO Superconductor ($\text{Y} + \text{Ba} + \text{Cu} + \text{O} \rightarrow \text{YBa}_2\text{Cu}_3\text{O}_7$):** High-temperature perovskite-derivative cuprate superconductor.
9. **Nitinol Memory Alloy ($\text{Ni} + \text{Ti} \rightarrow \text{NiTi}$):** Shape-memory intermetallic featuring martensitic-austenitic phase shifts.
10. **GaAs Semiconductor ($\text{Ga} + \text{As} \rightarrow \text{GaAs}$):** Direct bandgap III-V zincblende crystalline semiconductor.
11. **Water ($\text{H} + \text{O} \rightarrow \text{H}_2\text{O}$):** Polar covalent bent geometry ($104.5^\circ$) with hydrogen bonding potential.
12. **Halite Salt ($\text{Na} + \text{Cl} \rightarrow \text{NaCl}$):** Classic Face-Centered Cubic ionic coordination lattice.

## 🚀 Running the Instrument

The instrument requires **no build tools, node compilers, or bundlers**. It runs natively in any modern web browser supporting WebGL and ES6 modules.

### Option A: Local HTTP Server (Recommended for Three.js WebGL assets)
```bash
# Navigate to the workspace directory
cd "/Users/mahinigam/Codes/Periodic Table_Detailed"

# Launch Python 3 built-in HTTP server
python3 -m http.server 8000
```
Open your browser and navigate to:
**[http://localhost:8000](http://localhost:8000)**

### Option B: Direct Browser Launch
Open `index.html` directly in Safari, Google Chrome, Mozilla Firefox, or Microsoft Edge.
